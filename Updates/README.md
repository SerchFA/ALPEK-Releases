# Updates

Aquí vive la versión **vigente** de A.L.P.E.K.:

- `latest.json`: el manifiesto (versión, tipo, enlaces y huellas de cada archivo, novedades).
- `latest.json.sig`: su firma Ed25519 (base64). El programa **no** usa un manifiesto sin firma válida.

Esquema y funcionamiento: [README principal](../README.md).
